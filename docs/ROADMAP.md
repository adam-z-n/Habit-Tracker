# Roadmap

## Done (0.1, phase 1 plus the core of phase 2)

Habits with goals, smallest unit, activity types and custom measurements; one-tap logging; calendar with
retroactive editing; streaks and completion rates; Progress overview and per-habit dashboard (activity
donut, stacked bars over time, goal trend, period comparison); journal; reminders while the app is open and
calendar-file export; JSON and CSV export; restore with merge or replace; Google Sheets backup; installable
and offline.

## Done (0.3)

Simpler habits and habit editor, softer colors, a calmer journal (general journal or one habit's notes),
and to-do lists in place of the Progress tab.

## Next (rest of phase 2)

The Progress tab was removed in 0.3 at the owner's request, so the items below need a new home (for example
the habit's Stats page or Settings) if they are still wanted.

- Monthly and annual Wrapped summaries, saved or shared as an image.
- PDF report (habit summaries, statistics, charts, optional journal).
- Compare any two periods side by side (today: the period against the one before it).

## Later (phase 3)

- Native iOS wrapper (Capacitor) for Home Screen widgets and notifications that arrive when the app is
  closed. A web app cannot do either on its own. (In-app reminders were removed in 0.3; saved reminders
  are still in the data.)
- Push reminders for the web app (needs a small server to send them).
- Sync between devices (today: back up on one, merge-restore on the other).
- More backup destinations, journal enhancements, more chart types, per-habit theming.
